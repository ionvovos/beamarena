1. What Was Engineered

  • core/client.py: High-performance streaming client extracting native Chain-of-Thought (reasoning_content) and token telemetry from api.reflection.ai.
  • core/sandbox.py: Isolated scratch execution sandbox with timeout enforcement (15s) and strict path traversal containment.
  • core/agent.py: Autonomous Reinforcement-Learning style state machine that diagnoses bugs, applies file edits (<edit_file>), runs tests, and iteratively repairs code until passing.
  • core/ingest.py: 1M-token context packer extracting full AST symbol hierarchies (classes, functions, docstrings) across multi-file codebases.
  • app.py: Public Hugging Face Space application built with Gradio 6, featuring streaming reasoning traces, terminal drawer, and syntax-highlighted git diffs.
  • cli.py: Native CLI tool enabling Ion to run 1M-token repository ingestions and autonomous self-healing repairs on any local codebase.
